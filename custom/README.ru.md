# Custom Code & Extensions

Язык: [English (основной)](README.md) | Русский

## Описание

Этот каталог предназначен для опциональных расширений K1OS: модулей, патчей и вспомогательных инструментов.

Важно: K1OS не строится вокруг глубокой переработки Linux kernel. Базовый подход - минимальные изменения ядра и перенос продуктовой логики в user space и интеграционные слои ОС.

## Структура

### modules/
Собственные kernel modules для специфических задач K1OS (при необходимости).

Каждый модуль должен содержать:
- `Makefile` - конфигурация сборки
- `*.c` - исходные файлы
- `README.md` - документация модуля

### patches/
Точечные патчи к Linux kernel, если задачу нельзя решить через конфигурацию или user space подход.

Формат:

```text
patch-name.patch  - unified diff формат
README.md         - обоснование и инструкции применения
```

### tools/
Утилиты для разработки, проверки и интеграции кастомных расширений.

## Разработка

### Создание нового модуля

```bash
mkdir modules/my_module
cd modules/my_module
# добавить исходные файлы и Makefile
```

### Применение патча

```bash
cd kernel
patch -p1 < ../custom/patches/patch-name.patch
```
